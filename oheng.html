PROJECT 04

산딸기 어린이집

2D 공포 어드벤처

6인 팀 프로젝트 · 최우수상 / MVP팀장 · 게임 시스템 · 기능 통합
Unity C# Git

어린이집을 탐색하며 NPC와 대화하고 퍼즐·미니게임을 해결하는 스토리 중심의 2D 공포 어드벤처 게임입니다.

날짜별로 진행되는 스토리와 공간 탐색, 캐릭터 상호작용, 장면 전환 및 조명 연출을 연결하여 게임의 진행 흐름을 구성했습니다.

자료 링크
프로젝트 상세 README 및 구현 코드

게임 플레이 영상

썸네일을 클릭하면 영상을 확대하여 재생할 수 있습니다.

담당 역할

전체 맵 제작, Day1~Day6 씬 구성, NPC 이동 및 상호작용, 대화·선택지 UI, 미니게임, 기능 통합 및 디버깅

주요 게임 기능

  • 공간 탐색: 어린이집 내부를 돌아다니며 날짜별 스토리 진행
  • NPC 상호작용: 캐릭터 대화와 선택지를 통한 단서 확인 및 이벤트 진행
  • 퍼즐 및 미니게임: 각 장면에서 퍼즐과 미니게임 해결
  • 장면 연출: 씬 전환 및 조명 효과를 통한 공포 분위기 표현

주요 구현 흐름

  1. 플레이어 이동 · Collider 판정
  2. NPC / 이벤트 트리거 실행
  3. 대화 · 선택지 · 진행 상태
  4. 씬 전환 및 다음 이벤트

핵심 구현 및 문제 해결

핵심 과제 구현 및 설계 과정
01. 전체 맵 및 스토리 씬 구성 Unity Tilemap C#
Unity Tilemap을 활용하여 전체 탐색 맵을 제작하고 Day1~Day6 스토리별 씬을 구성했습니다. 날짜별 이벤트, NPC 상호작용, 미니게임을 연결하여 각 스토리의 진행 흐름에 맞게 기능을 통합했습니다.
02. NPC 상태 관리 및 대화 이벤트 Unity C# Collider
NPC 이동, 대화 트리거, 선택지 UI를 구현하고 스토리 진행에 맞게 연결했습니다. NPC 상태 변화로 대화 이벤트가 꼬이는 문제가 발생하자 대화 트리거를 별도 오브젝트로 분리하여 NPC 상태 변화와 대화 이벤트 처리 간 의존성을 줄였습니다.
03. 씬 전환 및 협업 과정의 충돌 대응 Coroutine Git PR
Coroutine을 활용하여 페이드·플래시 씬 전환 효과를 구현했습니다. 팀원들의 기능을 병합한 이후 씬 전환 효과가 다른 기능과 충돌하자 문제가 된 PR을 Revert했습니다. Coroutine 실행 순서를 조정한 뒤 다시 병합하여 문제를 해결했습니다.
04. 플레이어 이동 오류 해결 Unity C#
플레이어가 벽 모서리에 끼여 정상적으로 이동하지 못하는 문제가 발생했습니다. 이동 처리 과정에서 사용하는 이동 벡터 로직을 수정하여 해결했습니다.
05. 씬 재진입 및 상태 초기화 Unity C#
지하실에 재진입했을 때 기존 조명 효과가 다시 실행되지 않는 문제가 발생했습니다. 이전 진입 과정에서 유지된 상태 플래그를 초기화하도록 수정하여 재진입 시에도 조명 효과가 실행되도록 구현했습니다.

추가 구현 세부 사항
충돌이 발생한 PR을 Revert해 이전 상태로 복구하고, Coroutine 실행 타이밍을 조정한 뒤 재병합했습니다.

핵심 경험

여러 기능이 연결되는 게임 환경에서 상태 관리·이벤트 간 의존성·실행 순서를 고려했습니다. 개별 기능의 구현뿐 아니라 팀원들의 코드를 통합하는 과정에서 발생하는 오류를 추적하고, Git PR 및 Revert를 활용하여 협업 과정의 충돌을 해결했습니다.
