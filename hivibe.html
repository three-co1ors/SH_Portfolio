HiVibe

AI 기반 코드 분석·학습 플랫폼

2026.03 – 09 · 2인 졸업 프로젝트Frontend · Backend 개발
Java 21 Spring Boot Spring Data JPA MySQL Gemini API AWS EC2 / RDS Nginx Next.js TypeScript

코드의 정확성·효율성·가독성·스타일을 AI로 분석하고, 피드백을 학습 노트와 성장 기록으로 이어 주는 웹 서비스입니다.

단순히 코드 분석 결과를 제공하는 데 그치지 않고, 사용자가 자신의 코드를 개선하고 학습 과정을 기록하며 지속적으로 성장할 수 있도록 서비스를 구성했습니다.

담당 역할

서비스 아이디어 및 기획, 데이터베이스 설계, Gemini API 연동, 진단·학습 노트·마이페이지·배지 관련 REST API 개발, AWS 배포, Next.js·TypeScript 기반 웹 프론트엔드 공동 개발 및 API 연동

주요 서비스 기능

  • AI 코드 진단: 제출한 코드를 4가지 평가 기준으로 분석하고 항목별 점수·분석 근거·개선 코드 제공
  • 맞춤 학습: 진단 결과를 활용한 빈칸 학습 및 힌트 제공
  • 학습 기록: 진단 이력 조회·복원, 학습 노트 작성, 태그·즐겨찾기 관리
  • 성장 관리: 활동 통계, 연속 학습 일수, 배지를 통한 학습 현황 확인

주요 구현 흐름

  1. 사용자 코드 제출
  2. Gemini API 분석
  3. XML 파싱 · 서버 검증
  4. 가중치 점수 계산 → DB 저장

핵심 구현 및 문제 해결

핵심 과제 구현 및 설계 과정
🧠 AI 코드 분석 및 응답 구조화 Gemini API XML
평가 항목별 기준과 반환 형식을 프롬프트에 명시하고, AI가 제공한 피드백과 개선 코드를 XML 형식으로 받아 서버에서 파싱했습니다. 모델의 응답을 그대로 화면에 전달하지 않고, 서비스에서 처리할 수 있는 구조화된 분석 데이터로 변환했습니다.
🛡️ LLM 응답 검증 및 점수 계산 Java 21 Spring Boot
실제 AI 응답에서 필수 필드 누락, 형식 불일치 및 동일 결함에 대한 중복 감점 문제가 발생했습니다. 서버에서 필수값과 점수 범위를 검증하고, 정확성 40%·효율성 30%·가독성 15%·스타일 15%의 가중치를 기준으로 총점을 재계산하도록 구현했습니다. 동일한 결함이 여러 평가 항목에 중복 반영되지 않도록 평가 규칙도 보완했습니다.
🗃️ 데이터 모델링 및 참조 무결성 Spring Data JPA MySQL
원본 코드, AI 분석 결과, 최적화 코드, 사용자 진단 이력을 역할에 따라 별도 엔티티로 설계하고 저장·조회·삭제·복원 흐름을 구현했습니다. 진단 데이터 삭제 과정에서 FK 제약조건 오류가 발생하자 엔티티 간 참조 관계를 확인하고 연관 데이터의 삭제 순서를 조정하여 해결했습니다.
📝 진단 이력 및 학습 노트 API REST API Spring Boot Spring Data JPA
이전 진단 결과의 조회 및 복원 기능을 구현했습니다. AI 분석 결과를 학습 과정으로 이어갈 수 있도록 학습 노트 CRUD와 태그·즐겨찾기 관리 기능을 개발했습니다.
⚙️ 사용자 활동 추적 및 배지 Spring Data JPA MySQL
진단 데이터만으로 사용자 활동을 집계하면 학습 활동이 누락되거나 집계 기준이 복잡해질 수 있다는 점을 고려했습니다. UserActivityLog를 별도 엔티티로 분리하여 진단 및 학습 완료 이력을 관리하고, 날짜별 활동과 연속 활동 일수를 계산해 활동 통계 및 배지 획득 조건에 연결했습니다.
☁️ 배포 환경 구축 및 오류 대응 AWS EC2/RDS Linux Nginx HTTPS systemd
AWS EC2에서 애플리케이션을 실행하고 RDS 기반 데이터베이스를 연결했습니다. Nginx로 프론트엔드·백엔드 요청 경로를 구분하고 HTTPS 및 systemd 기반 실행 환경을 구성했습니다. 제한된 인스턴스의 메모리 부족으로 빌드가 중단되는 문제는 스왑 메모리를 설정하여 해결했습니다.

추가 구현 세부 사항
진단 삭제 시 자식 엔티티부터 삭제하도록 순서를 조정했습니다. 의존성 설치·빌드 중 메모리 부족으로 프로세스가 종료되는 문제에 대응했습니다.

핵심 경험

LLM의 결과를 그대로 사용하는 대신 출력 규약·검증 로직·데이터 구조·운영 환경을 함께 설계하여 실제 서비스에 연결했습니다. AI 응답의 검증 책임을 서버가 갖도록 구현하고, 데이터의 생성과 조회뿐 아니라 삭제 시 참조 무결성 및 사용자 활동 집계까지 고려한 데이터 모델링에 집중했습니다.
